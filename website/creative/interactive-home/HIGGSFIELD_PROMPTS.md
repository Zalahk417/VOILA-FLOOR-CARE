## Sequential generation procedure

Never submit the five final clips as unrelated generations.

For each scene:
1. submit one scene;
2. wait for completion;
3. inspect the endpoint for continuity;
4. extract the actual final decoded frame;
5. approve or re-roll that scene;
6. use the approved final frame as the next scene start image;
7. continue.

The actual rendered endpoint, not an independently imagined destination still, controls the hand-off.
